ZERO GAME — enemy reference crop pack

This pack contains approximate individual crops from the user-provided Snow Bros-style enemy collage.
The source image advertises 40 enemies, but visually contains additional variants/decorative elements;
therefore 48 crop slots are included so nothing potentially useful is silently discarded.

IMPORTANT:
- These are reference crops, NOT finished game-ready transparent sprites.
- The original blue/ice background is retained in the crops.
- The collage shows mostly static poses; it does not contain complete animation frames.
- Each crop needs background cleanup, transparent cutout, sprite alignment, and animation work before Phaser integration.
- No existing enemy identity, gameplay, or repository file has been changed by creating this pack.
